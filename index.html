¿Qué es?

ThenBlex es un programa/script de bots para servidores de MCPE 0.15.10 / Craftsman. Este script está desarrollado por ssamut25. El script está en fase de pruebas y consideramos ir mejorándolo a futuro, pero nuestra última versión 2.0.1 cuenta con AutoChatCode (esta función permite escanear el chat y poner el código de verificación automáticamente) y también cuenta con AutoRegister.

ThenBlex por el momento será público y gratuito, pero cuando llegue a sus últimas versiones pasará a ser un script de paga, dependiendo de cómo vaya el uso del mismo.

Version: 2.0.1
