ThenBlex

ThenBlex is a bot program/script for Mcpe-0.15.10/Craftsman servers. This script is developed by ssamut25. The script is currently in the testing phase, and we plan to improve it in the future, but our latest version 2.0.1 features AutoChatCode, a function that allows scanning the chat and automatically entering the verification code, and it also features AutoRegister. ThenBlex will be public and free for now, but when it reaches its latest versions, it will become a paid script, depending on how the use of the script goes.
